# AS260 - [Session Title]

## Description

This repository contains the material for the SAP TechEd 2026 session **AS260**.

## Overview

In this session, you are going to experience the Financial Closing Assistant and the SAP AI agents which are part of it:

- Journal Entry Agent
- Accounting Accruals Agent
- Accounts Payable and Accounts Receivable Clearing Agent
- Analytical Business Insights Agent

You will be working in an SAP S/4HANA Cloud system and in Joule or Joule Work. Start with the Getting Started guide below for system access details and first steps, then proceed to any of the agent exercises in whichever order interests you most.

## Requirements

- Access to the SAP S/4HANA Cloud test system (URL and credentials provided in each exercise)
- A participant number (XX) assigned to you at the session
